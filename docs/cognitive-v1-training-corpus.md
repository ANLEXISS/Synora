# Cognitive Core V1 corpus

The reproducible corpus is generated by `tools/cognitive_v1_pipeline.py` from
the tracked declarative scenarios in `testdata/cognitive-v1/scenarios.jsonl`.
It contains exactly 40,000 train examples, 5,000 validation examples and
5,000 independent-test examples.

Every record carries a schema version, canonical snapshot facts, the fixed
86-dimensional vector, explicit labels, provenance, and split keys. The split
generator namespaces family, template, seed, topology and sequence keys by
split. `validation-report.json` must therefore show zero intersections for all
five keys before a bundle is used by the runtime.

The reports include a confusion matrix, precision and recall per class,
confidence/calibration gap, class imbalance counts, frequent errors and the
independent holdout result. Labels are copied from declarative scenario
templates; no model prediction or danger expectation is used to create
a label.

The generated JSONL and checkpoints remain build artifacts. The source
scenarios, generator, manifest and reports are versioned; no model weight or
State Encoder V4 artifact is changed by this pipeline.
